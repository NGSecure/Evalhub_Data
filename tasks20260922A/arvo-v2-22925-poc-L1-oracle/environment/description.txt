A regex pattern containing a numeric code-point escape (e.g. \x{...}) drives oniguruma's pattern parser, while running under the EUC-JP encoding, to build a string node from that code point's raw byte encoding using a wildly out-of-range end pointer — an UndefinedBehaviorSanitizer array-index-out-of-bounds error while indexing the small fixed-size stack buffer that is supposed to hold one code point's encoded bytes.

Root cause: to turn the escape's numeric code point into bytes, the parser first asks the active encoding, via a length-only query, how many bytes the code point will need, then separately calls the encoding's real byte-emitting routine to actually fill a small stack buffer, treating whatever that second call returns as the number of bytes written and computing "buffer start + that count" as the one-past-the-end pointer for the new string node. For EUC-JP these two routines can disagree: the length-only query decides the byte count solely by table-looking-up the code point's most-significant non-zero byte, while the byte-emitting routine independently tests each byte position's bits for non-zero and only emits a byte for a position that is non-zero. When a code point's most-significant byte is non-zero but its middle byte happens to be exactly zero, the emitting routine skips the middle byte and writes one byte fewer than the length-only query promised. The emitting routine does carry an internal consistency check that re-derives the expected length from the same leading-byte table and compares it against what was actually written, but on a mismatch it does not correct the output — it instead returns oniguruma's generic negative "invalid code point value" error constant in place of a byte count. Unlike the earlier length-only call, whose result the parser does check for being negative, this second return value is used unchecked: the negative error constant is added directly to the stack buffer's base address, yielding a pointer several hundred bytes before the start of the 7-byte buffer, which is the out-of-bounds index the sanitizer reports.
