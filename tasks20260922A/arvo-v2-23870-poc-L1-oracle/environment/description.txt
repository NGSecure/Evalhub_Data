LibRaw (UBSan build): a corrupted TIFF-based raw file reaches the demosaic engine's horizontal/vertical edge-direction classifier and drives it to read one element past the end of a per-pixel three-channel float working buffer. Before choosing between horizontal and vertical interpolation at each pixel, the algorithm first works out, once per scanline, which of the two non-green color channels is expected to sit at the very first non-green sample position in that row; it derives this purely from the file's own per-row color-filter-array query, without the same fourth-filter-code-to-green normalization that this algorithm's own setup step applies elsewhere when building its raster working array. That per-scanline channel value is then also flipped (red-to-blue and back) inside the direction classifier itself whenever a pixel at the opposite screen parity is being examined. For a well-formed two-color-per-row Bayer-style sensor layout, the row's designated non-green position is guaranteed to be red or blue, so flipping it always lands on the other of the two -- but this file's color-filter-array description is corrupted such that the position the classifier expects to be red-or-blue instead reports green, or the sensor's rarely used fourth filter code, and flipping that unexpected value produces an index one past the last valid slot of the three-channel float array, which is what UBSan flags. The commit recorded against this bug only tightens bit-depth/sample-format validation for the floating-point and deflate variants of DNG's own raw-decoder-selection logic, used during file-format identification -- a stage that runs long before, and has no data or control dependency on, the per-row color-filter-array bookkeeping inside the demosaic direction classifier described here; that commit does not plausibly explain this crash regardless of whether the underlying file happens to carry DNG-style metadata, since the demosaic stage operates purely on the already-decoded pixel buffer and the file's declared filter layout, not on which raw decoder produced that buffer.
