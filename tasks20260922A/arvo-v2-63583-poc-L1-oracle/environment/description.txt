libultrahdr, when encoding a raw YUV (planar 4:2:0) image to a JPEG through its bundled libjpeg-turbo, triggers a 1-byte heap-buffer-overflow READ inside libjpeg-turbo's DCT sample-conversion stage (third_party/libjpeg-turbo/jcdctmgr.c), reached via jpeg_write_raw_data during raw-data compression; ASan build. Root cause: the encoder helper drives libjpeg-turbo in raw-data mode, handing it one MCU-row batch of per-plane scanline pointers at a time, and libjpeg-turbo's DCT stage always consumes a full MCU-aligned row width for every component — that is, each plane's width rounded UP to the compression batch size (16 for luma, 8 for chroma). To keep those reads in bounds the helper is supposed to copy short rows into padded intermediate buffers before passing them down, but it decided whether padding was needed using a single flag derived ONLY from the luma stride (luma_stride < aligned_luma_width). That one luma-derived flag also gated whether the chroma (Cb/Cr) rows were routed through padded buffers. Consequently, when the supplied luma stride was already large enough that no luma padding was requested, the chroma rows were fed to libjpeg-turbo directly even though the chroma stride was smaller than the MCU-aligned chroma width; the DCT sample-conversion then read one byte past the end of the last chroma plane's input heap buffer while gathering a full MCU-aligned chroma row. The underlying defect is that luma and chroma padding requirements were coupled to a single stride comparison instead of being evaluated independently per plane, so any component whose own stride was below its own MCU-aligned width could be read past the end of its backing buffer. The remediation splits this into independent luma and chroma padding decisions (each comparing that plane's stride against its own MCU-aligned width) and copies each plane's rows into per-plane intermediate MCU-width buffers whenever its own stride is insufficient, so libjpeg-turbo never reads beyond a plane; the accompanying decoder path received the analogous per-plane alignment and last-row bounds guards.
